# Soham Ahirrao — Portfolio

**SOHAM // SYSTEM ONLINE**

Personal portfolio website of Soham Ahirrao — Software Developer · Cloud · DevOps · Full Stack.

## Stack

- **Framework:** Next.js 14 (App Router)
- **Styling:** Tailwind CSS
- **Language:** TypeScript
- **Icons:** Lucide React
- **Deployment:** Vercel

## Features

- Dark / Light mode with zero flash
- Interactive architecture diagrams (OmniGrid, MusicNation)
- SohamOS terminal — type `help`, `omnigrid`, `sudo hire soham`
- Konami code easter egg
- Boot sequence loading screen
- Live uptime counter
- Typewriter status animation
- Fully responsive — mobile, tablet, desktop
- Resume page with print-to-PDF support
- Accessible (ARIA, keyboard navigation, reduced motion)

## Routes

| Route | Description |
|---|---|
| `/` | Full portfolio |
| `/resume` | Resume — view online + print as PDF |

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)

## Deploy

Connect this repo to [Vercel](https://vercel.com) — it auto-detects Next.js and deploys in ~2 minutes. Free tier.
